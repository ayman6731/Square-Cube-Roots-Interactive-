Core Concepts & Rules

Master the fundamentals and special technical tricks before taking the challenge!

1. Square Roots ($\sqrt{a}$):

Every positive real number has two square roots: a positive principal root and a negative root.

For example, $\sqrt{25} = 5$ and $-\sqrt{25} = -5$.

2. Cube Roots ($\sqrt[3]{a}$):

Every real number has exactly one real cube root, and it preserves the original sign.

For example, $\sqrt[3]{-125} = -5$ because $(-5)^3 = -125$.

3. Special Tricks & Traps (Highlights):

Trick 1 (Equations Trap): If $x^2 = 16$, never say $x = 4$ only! Always write $x = \pm 4$ when taking the square root in equations.
Trick 2 (Distributivity Trap): $\sqrt{9 + 16} = \sqrt{25} = 5$, which does NOT equal $\sqrt{9} + \sqrt{16} = 3 + 4 = 7$.
Trick 3 (Negative Under Square Root): $\sqrt{-16}$ has no meaning in $\mathbb{R}$ (Undefined / $\phi$).
Trick 4 (Square Root of Square Variable): $\sqrt{x^2} = \vert{}x\vert{}$, and if $\sqrt{x^2} = -x$ then $x \le 0$.
